# kashima-fishing-notebook

鹿島灘 釣り手帖。神栖・鹿嶋周辺の魚、餌、仕掛け、結び方と地域の注意点を調べる静的Webアプリです。

## ローカルで開く

このリポジトリを静的Webサーバーで配信します。例:

```sh
python3 -m http.server 8000
```

http://localhost:8000/ を開いてください。入口は `index.html` で、ビルドやパッケージのインストールは不要です。

## GitHub Pages

`main` ブランチのルート (`/`) を公開元に設定します。画像、スクリプト、CSSは相対パスのため、リポジトリのサブパスで動作します。`.nojekyll` で静的ファイルをそのまま配信します。

## 内容

- 魚図鑑33項目（海・汽水25、淡水8）と独自の模式図
- 結び方8件。ユニ・改良クリンチは5段階の独自図解、追加6件は文章手順と公式資料へのリンク
- 釣具・仕掛け、餌、フナの糸切れ診断、カワハギの餌とポイント選び
- 魚ごとの食べ方・下ごしらえ・豆知識と、持ち帰り方・アニサキス対策（`kitchen.js`。毒のある魚は食べ方を載せず、豆知識は「出典」「一般」で区別）
- フナの糸切れ診断に、結び直し・ハリ穴のバリ・チェック表を追加
- 魚ページの「狙い方」から、特徴・生態 / 釣り方・仕掛け / 食べ方へ直接ジャンプ。魚ごとの生態 (体の特徴・すみか・食性・季節の動き) と、なぜその仕掛け・場所で釣れるかの理由
- 魚ごとの釣り方・仕掛けの詳しい解説 (`tackle-detail.js`。道具の一覧、手順、時期・時間帯、よくある失敗、規制の注意。号数などは一般的な目安)
- 全項目検索、水域・季節・注意魚の絞り込み、お気に入り、ブラウザーの戻る操作
- 鹿島港・北浦周辺の地域ルールと各項目の出典・確認日

## 情報とプライバシー

お気に入りはブラウザーのlocalStorageだけに保存し、サーバー同期やアカウント登録はありません。実行時の外部CDN・API依存はなく、出典リンクは利用者が開いたときにアクセスします。

釣果、潮汐、天候のリアルタイム情報は取得しません。規制や立入条件は変わるため、釣行前に管理者の最新案内を確認してください。魚や結びの図は学習用の模式図で、魚の同定、食用の安全、結束強度を保証するものではありません。
